# Warehouse Inventory Tracking using Doubly Linked List

## Problem Statement
Develop a Warehouse Inventory Tracking System using a Doubly Linked List.

## Features
- Add Product
- Display Products Forward
- Display Products Backward
- Search Product
- Delete Product
- Exit

## Data Structure
Doubly Linked List

## Programming Language
C++

## Description
Each node stores:
- Product ID
- Product Name
- Quantity
- Previous Node
- Next Node

The doubly linked list allows the inventory to be traversed in both forward and backward directions.
